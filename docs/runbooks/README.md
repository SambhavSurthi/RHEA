# runbooks/ — Repeatable operational procedures

Step-by-step procedures for operating RHEA safely. A runbook is written so a different agent can execute it without guessing.

## Existing runbooks

| File | Purpose |
|---|---|
| `TEMPLATE.md` | Required format for new runbooks |

Add runbooks for: full-stack startup/shutdown, incident rollback, evaluation, volume/data recovery and dependency upgrades. Each new runbook must be linked from `docs/NAVIGATION.md`.
