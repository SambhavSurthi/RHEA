# solved/ — Closed issues with permanent solutions

Move an issue here only after:

1. it was assigned before work began (`AGENTRULES.md` §5.1),
2. `## Solution` is written in the file,
3. verification results are recorded in `## Verification`,
4. `status: closed` and `updated` are set.

The moved file is the permanent record. Never delete it. To reopen, create a new issue that links back to this file.
