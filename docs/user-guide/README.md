# user-guide/ — Researcher-facing documentation

Docs here explain how to **use** RHEA, not how to build it. Write for a researcher who has never seen the codebase.

## Rules

- Task-oriented titles ("Upload your first paper", "Read a citation", "Start a new chat").
- Show exact UI controls and expected results; avoid implementation details.
- Never include secret values or assume production credentials.
- Copy `TEMPLATE.md` for every new guide and link it from `docs/NAVIGATION.md`.
